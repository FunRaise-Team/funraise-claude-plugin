# Funraise 資料源對照

工具名稱的前綴就是下表的 `mcp_id`（例如 `buildings__search_buildings`）。使用者的設定可能只開了其中一部分；實際可用的以工具清單為準。

## 成交與市場

| mcp_id | 內容 | 適合的問題 |
|---|---|---|
| `actual-price-sale` | 內政部實價登錄成交資料（住宅／商用） | 某區某類物件的成交價、單價、件數 |
| `actual-price-rental` | 不動產租賃實價登錄 | 租金行情 |
| `actual-price-presale` | 預售屋買賣定型化契約備查 | 預售案成交價 |
| `rtube` | 即時待售物件（仲介掛牌，含總價與單價） | 現在市場上在賣什麼、開價多少 |
| `leju` | 全國區域市場的量價、待售存量、委售與委成比、轉售賺賠時間序列（2013 年起） | 區域行情走勢、市場熱度 |
| `mops-property` | 上市櫃公司「取得或處分資產」重大訊息（商辦／廠房／土地買賣、租賃、合建等） | 上市櫃公司買了／賣了哪些不動產 |

## 建物與標的

| mcp_id | 內容 | 適合的問題 |
|---|---|---|
| `buildings` | 商辦大樓基本資料、樓層、面積、用途、認證、周邊捷運 | 某棟商辦的規格 |
| `properties` | 不動產物件目錄 | 物件基本資料 |
| `future-dev` | 未公告／已公告的未來建案 | 某區未來會有哪些新案 |
| `taipei-licenses` | 台北市建造執照與使用執照 | 某基地的建照、使照 |
| `dd-memo` | 一棟建物的建照、使照、預售與成交紀錄按時間排列 | 一棟建物的完整履歷（盡職調查） |

## 土地與區位

| mcp_id | 內容 | 適合的問題 |
|---|---|---|
| `land-info` | 全國地籍（座標 ↔ 地號、邊界、面積、條件檢索、段別清單、門牌轉座標）；台北市另有使用分區與法規 | 地號在哪、多大、屬於什麼分區 |
| `urban-renewal` | 全台都市更新地區／單元與範圍 | 某處是否在都更範圍內 |
| `industrial-parks` | 全國 212 個產業園區與範圍，可查園區內公司與地號 | 園區裡有哪些公司、哪些地號 |
| `development-zones` | 全台市地重劃／區段徵收地區 | 某處是否在重劃區、區徵區內 |
| `areas` | 行政區與商圈洞察、產業分佈 | 某行政區或商圈的概況 |
| `cities` | 縣市資料 | 縣市層級的基本資訊 |
| `mrt` | 捷運站與路線 | 鄰近捷運站 |
| `public-infras` | 學校、公園、醫院、政府機關等 | 周邊公共設施 |

## 企業

| mcp_id | 內容 | 適合的問題 |
|---|---|---|
| `business-registry` | 全國商工登記當期資料（統編、地址、資本額、行業別） | 某公司的統編、登記地址；多家公司一次查用批次工具 |
| `company-registry` | 公司登記歷次異動（資本額、地址、負責人、新設、解散） | 某公司何時增資、搬遷、換負責人 |
| `key-enterprise` | 商辦承租重點企業（Funraise 整理） | 哪些重點企業租在某棟或某區。**沒有統編欄位**，要統編請接著用 `business-registry` 的批次工具 |
| `stakeholders` | 公司間關聯、董監事、法人代表 | 公司背後的關係人 |
| `providers` | 不動產服務商目錄（仲介、代書、建商） | 找服務商 |

## 知識與內容

| mcp_id | 內容 |
|---|---|
| `ai-info` | Funraise 編寫的市場知識條目 |
| `blog` | Funraise 部落格文章 |
| `ecosystem-blog` | Funraise 生態系夥伴的專欄文章 |

## 需要額外開通

| mcp_id | 內容 | 說明 |
|---|---|---|
| `transcripts` | 建物／土地謄本、地址解析 | 部分工具**會產生費用**，一律先 dry-run 估價，經使用者同意才執行 |
| `gsc` | 團隊自有網站的 Google Search Console 成效 | 需團隊管理員先連結 Google 帳號，且只在團隊設定中可用 |
| `ga4` | 團隊自有網站的 Google Analytics 4 流量與轉換 | 同上 |
